Candies sorter

every candy is one small question; the model says which bowl it belongs in

Where the candies went

Rows are the true colour, columns the bowl the model chose. A wrong bowl shows up as a wrong-coloured candy in the bowl. The reference rule is "nearest hue" (99.9% easy, about 99% normal, 95% hard). Numbers are hard for small models: try "colour in words" for them, and RGB for a large model.

Idea: Matthew Berman's video "We need to talk about Jev...". The design and code are our own.
