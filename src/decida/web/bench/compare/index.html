Models to compare

Thirty clear-cut questions written by hand: ten choices, ten scores, ten yes/no. It shows which model gets the easy things right, how sure it is when it is wrong, and how long it takes. It is a smoke test, not a benchmark.

Every question, model by model

Write your own test case: the situation, the question, its options and the correct answer. Cases are saved in this browser. They appear in the example list of the side-by-side view, and, when they have a correct answer, they can be included in the labelled run.
