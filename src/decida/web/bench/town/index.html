Live decision lab Idea: Matthew Berman
Advanced

The model decides: every citizen asks the model one typed question (what to do, where to go, how they feel). Works with strong models. The model reads: one request reads the announcement (which place, is it a danger, is it an offer); each citizen's temperament, job and trust in the sender turn that into an action. This suits small local models, which read text well but cannot tell one person's reaction from another's.
