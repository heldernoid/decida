Decisions in one forward pass.

Decida is a small local runtime for System One models. Point it at a Hugging Face id, and it serves typed questions over one REST API and MCP. Every answer is a probability distribution, never generated text, so it is fast, cheap and always valid.

$ decida serve --model decidabert=helmo/DecidaBERT-large

    Decida runs models
    It loads, serves and tests them. Training and data generation are outside its scope. It can also forward requests to a hosted endpoint you choose, under a spend cap you set.
    
    
    Safe by default
    Weights load as tensors only, from safetensors or weights-only files. Code that ships inside a model repo is never run, and third-party code keeps its licence file beside it.
    
    
    About this page
    Served by your own Decida server. The playground, the smoke checks and the benches call the models you have loaded, live. The batching animation under Under the hood is an illustration.
