decida

A local runtime for System One models. Send a state and typed questions, get a probability distribution for each one back from a single forward pass, with no generated text. It serves REST and MCP and includes a testbench of small games.

uv tool install git+https://github.com/heldernoid/decida
decida serve        # then open http://127.0.0.1:8000
This page is a static preview. The answers in the simulator below are made up in your browser; no model is running. For the real thing, install decida from GitHub.

Three question types

      

        

          

            type
            you give
            you get back
          

          

            choice
            2 to 255 options, each with a description
            a probability for every option
          

          

            score
            an ordered list of 2 to 32 levels, lowest first
            a probability for every level, and the expected level
          

          

            noul
            a yes/no question about the state
            the probability that it is true
